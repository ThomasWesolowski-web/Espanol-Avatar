# Hablemos mit Lucía

Spanisch lernen im Videoanruf mit Lucía, einem sprechenden Avatar aus Sevilla.

Öffne die Seite über GitHub Pages in Safari (iPhone) oder Chrome, erlaube das Mikrofon und trag einen kostenlosen Google-Gemini-Schlüssel (aistudio.google.com/apikey) ein. Ein Anthropic-Schlüssel geht auch. Der Schlüssel bleibt nur im eigenen Browser gespeichert.
